# Baby Solids Tracker — Phone PWA

This is a phone-friendly Progressive Web App. It stores food/meal data in the browser's localStorage.

## Features
- Food library with tried checkboxes
- Serving instructions and safety notes
- Common-allergen labels
- Meal logging with date, time, foods and notes
- Home-screen installable when hosted over HTTPS
- Offline caching after first load

## Important
The guidance is educational and follows general CDC complementary-feeding guidance. It is not medical advice. Follow your pediatrician's guidance, especially for allergy concerns.
